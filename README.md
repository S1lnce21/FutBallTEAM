# Практическая работа № 1.2 - Связи таблиц

## Предметная область
Футбольный клуб. Предметная область описывает связь между командами и игроками.

Выбран тип связи: **Один-ко-многим (1:N)**.

## Модели и связи
- **Team** (Команда): поля `name`, `city`.
- **Player** (Игрок): поля `firstName`, `lastName`, `position`, `number`.
- Связь реализована парой методов: `Team.hasMany(Player)` и `Player.belongsTo(Team)`. 
Внешний ключ: `teamId` в таблице игроков. Псевдонимы: `players` и `team`.

## Инструкция по запуску
1. Установить зависимости: `npm install`
2. Запустить скрипт: `node app.js`
Скрипт создаст базу, добавит команды и игроков (используя метод `createPlayer`), выполнит жадную загрузку через `include` и выведет результат в консоль.
